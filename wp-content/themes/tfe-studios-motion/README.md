# TFE Studios Motion 0.2.0

Staging candidate. Native WordPress theme retaining the supplied v3.1 identity and six hash routes. Company PDFs are excluded from distribution.

Install the theme ZIP only on staging. Edit company content through TFE Content, and use TFE Services / TFE Portfolio for ordered cards. Server delivery is disabled by default; publish a privacy policy, configure external SMTP and verify delivery before an administrator enables it. Direct email remains available.

Three.js 0.161.0 is bundled locally in js/vendor. Original logo exports are preserved. Hash sections share one indexable document. Separate canonical routes require approval.

See the repository README, DEPLOYMENT.md and TESTING.md for build instructions, actual verification limits and rollback. No production deployment is authorized; the supplied 0.1.0 starter is not a verified production rollback.
